# 亦伴 v0.6 操作教学片

用途：回答用户「怎么操作」，自主完成，不要求用户选择宣传片风格。保留真实页面、镜头可读性与独立终检的方法；按教学需要使用 FFmpeg 定帧剪辑，不使用 Ink Press、Gallery 运动卡、BGM 或 Remotion 动效工作台。此片不是宣传片，也不是连续屏幕录像；真实操作截图剪辑，等待过程省略。

产品依据：当前 src/PersonalHome.tsx、PersonalDemo.tsx、server/personal-agent.mjs 与 v0.6 验证记录。步骤1—9采自发布源码的公开交互演示；步骤10—11读取既有本机真实结果，没有追加模型调用。公开示例从同源静态文件提供，不连接真实调度器；演示跟进最后停用。完整版本真实定期任务未在本视频中启用。

视觉：复用产品背景 #f8f9f5、正文 #29352e、强调 #3d654e、表面 #edf2ed。1920×1080，24fps；公开截图1440×900，本机结果截图1280×720。中文使用系统黑体。标题64px，主要步骤提示64px，状态标签38px。固定画面、少量淡入，不旋转/晃动/节拍冲击，给按钮和内容充分阅读时间。没有电影式音效，中文系统 Tingting 配音，无背景音乐。画面时长由每章音频实际长度加2秒确定，避免截断讲解。

素材：截图与DOM目标区域坐标记录在 captures/layout.json。全页素材仅截标签页内容，不含浏览器地址栏、账户设置或凭证。真实结果仅包含公开项目实践的通用目标、已有回顾与报告用量；不采集私人原始日志。逐章有「公开示例」「已有真实结果」标签。
