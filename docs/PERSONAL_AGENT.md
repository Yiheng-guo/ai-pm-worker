# 亦伴 · 懂项目背景的个人产品研究助理

本版把已有亦伴的文档交付与造物的原型制作连接到同一项目过程。核心体验是：知道项目背景，搜集并保存真实证据，判断能力是否值得做，形成可验收需求和行动项，再按需制作交互原型。

## 实现与研究取舍

- nanobot 是实际 Agent 运行时，负责结构化研究产物和模型调用；本机模型桥接已登录的 Codex。上游版本/提交与许可证以运行环境安装记录和许可文件为准。
- 亦伴继续承担统一项目入口、证据、需求、行动项、运行记录、记忆纠正与评测呈现。旧版文档功能保留为可比较的基线。
- 造物作为原型制作能力。需求被传入原型工具，保存浏览器前端交付物与迭代版本，不把前端原型等同完整业务系统。
- Hermes Agent 作为持久记忆和技能积累的机制参考；Rowboat 作为项目工作台和证据/交付物组织方式的体验参考。它们的运行时未被混进本项目，不能把参考设计说成完整复刻其能力。
- 本版重点验证可追溯证据和可纠正项目记忆，没有宣称模型权重会持续学习、已经实现成熟自动技能晋升，或长期个人化效果已被证明。

## 数据关系

一个项目包含背景、目标、约束和可修改记忆。研究运行关联项目快照、历史运行、来源、模型原始结果与真实用量。输出中的事实断言、需求和行动项可引用已保存证据。原型关联研究运行与需求，版本和反馈保留。评测报告与原始记录单独归档，避免把内置样例当实测。

证据正文来自公开 HTTPS 网页或官方 README。抓取记录有原始链接、实际读取链接、时间和 SHA256。哈希用于确定本次材料快照，不能证明来源内容真实或能力效果可靠。记忆允许用户纠正，来源用于区分用户确认、研究结论与受控测试设定。

## 使用与评测

启动和连续任务步骤见 [演示指南](DEMO_GUIDE.md)。真实配对评测的样本、指标、限制与运行方法见 [评测协议](EVALUATION_PROTOCOL.md)。

默认本机地址 `http://127.0.0.1:4310`，`npm run agent:start` 同时启动造物。个人 Agent 独立工作空间使用 `data/personal-agent/` 数据库，运行原始档案在 `.runtime/records/`，评测档案在 `data/evaluations/`，均不进入 Git。本机登录状态只支持本机调用，不自动转换为任意线上模型 API 授权；原始运行可能包含项目背景，应在分享前检查。模型用量来自实际返回的字段，订阅调用没有单任务账单时，现金成本显示不可换算。

## 当前交付边界

本版是单用户、本机运行的完整产品作品与实测演示。可以串联项目研究到浏览器原型；模型结论需要核实，搜索可能失败，资料可能过时或截断，记忆也可能记录错误。没有常驻云端、后台调度和渠道授权时，不承诺电脑关机后的监测与消息提醒。任何未测试能力应明确标记为未测，不能用一个演示推出总体效果。
